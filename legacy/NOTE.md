# Legacy code (as published with the paper)

These are the original scripts the paper describes (`final_gpu.py`: CLI, `app.py`: Streamlit GUI) and the original
README, kept **unchanged** for reference and reproducibility. They are not used by the package in `src/`.

The maintained, tested reimplementation is in the repository root; its `paper` preset reproduces the behaviour of
`final_gpu.py`. See the root `README.md` and `AUDIT.md` for what was found when running the original code.
